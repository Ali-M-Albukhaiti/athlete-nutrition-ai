# 🏃‍♂️ Athlete Nutrition AI System

## 📌 Project Overview
This project is an AI-powered system that predicts an athlete’s daily calorie needs based on inputs such as age, weight, sport type, and training intensity.

The system combines:
- Machine Learning (Decision Tree model)
- Backend API (FastAPI)
- Frontend UI (React)

---

## ⚙️ Tech Stack
- Frontend: React
- Backend: Python (FastAPI)
- ML: Scikit-learn (Decision Tree Regressor)
- Data: Synthetic dataset

---

## 🧠 Machine Learning
The model predicts calorie requirements using features like:
- Age
- Weight
- Sport type
- Training intensity
